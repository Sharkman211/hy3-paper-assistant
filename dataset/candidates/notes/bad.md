# 研究目标
本文提出了一种全新的实时目标检测算法 D-FINE-seg，彻底解决了实例分割的所有难题。

# 核心方法
模型采用 Transformer 主干，并引入扩散模型（Diffusion Model）生成 mask，在 COCO 数据集上取得了 95% 的 mAP。训练时使用自监督对比学习进行预训练。

# 主要创新点
- 首次将神经网络应用于实例分割任务。
- 提出了一种端到端的无锚框范式。
