# 1. 研究目标
- 核心问题：传统线性多因子模型难以刻画因子间的非线性与时变关系；因子收益存在制度性结构变化，静态加权失效（摘要与引言）。
- 动机：希望用注意力自动学习因子间相关结构（引言）。
- 待填补空白：原文未充分提供（未明确陈述前人工作缺口，仅指出传统模型不足）。

# 2. 核心方法
- 输入处理：每只股票当日 64 维因子（估值、成长、动量、质量、波动率类），做截面 z-score 标准化。
- 模型设计：提出 AttnCross（横截面注意力模型），每日对全市场股票用因子序列作为 token，股票为 token，经 3 层 Transformer 编码器（head 8，hidden 128）输出个体收益分数，注意力层输出下期超额收益预测。
- 损失函数：训练目标为排序损失（pairwise ranking loss，成对排序损失），用于学习股票收益排序。
- 组合构建：按分数排序取前 10% 多空，月度调仓，单边 0.1% 交易成本。

# 3. 主要创新点
- 提出 AttnCross 横截面注意力模型，将股票作为 token、因子序列作为输入，通过注意力层输出下期超额收益预测，替代传统线性 IC 加权与静态加权。
- 将注意力机制应用于自动学习因子间相关结构，以应对因子收益制度性结构变化（引言动机的方法化）。

# 4. 实验结果与分析
- 实验设置：数据为中国 A 股非 ST 普通股（剔除停牌），样本外区间 2015-2023 年，扣费后评价；基线包括 IC 加权、随机森林、XGBoost。

本文报告的结果：
- AttnCross：多空组合年化收益 18.3%，信息比率（IR）2.1，最大回撤 14.2%。
- 注意力权重可视化：下跌市模型更依赖质量/低波因子，与风控直觉一致。

已有方法的结论（基线结果）：
- IC 加权：年化 11.2%，IR 1.3，最大回撤 22.5%。
- 随机森林：年化 14.0%，IR 1.6（摘要给出，未提供最大回撤）。
- XGBoost：年化 14.0%，IR 1.6，最大回撤 19.8%。
对比结论：AttnCross 样本外年化较 IC 加权提升 7.1%、IR 提升 0.8；较随机森林/XGBoost 年化提升 4.3%、IR 提升 0.5，且回撤更小，显著优于基线。
