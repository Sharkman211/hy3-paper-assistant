# 1. 研究目标
- 核心问题：实时目标检测在边缘设备（手机、车载模组、无人机）上因计算冗余导致帧率不足；传统检测头在分类与定位分支间存在表征错位，导致小目标与遮挡目标召回偏低；静态标签分配（如 SimOTA 的固定代价矩阵）在尺度剧烈变化的边缘场景中匹配不稳定。
- 动机：边缘设备算力有限且内存带宽紧张，自动驾驶、智能监控与移动机器人等场景对延迟与精度的平衡提出严苛要求。
- 待填补空白：提出面向边缘部署的统一检测架构，在保持高精度的同时显著降低推理开销，解决分类-定位不一致并提升小目标匹配稳定性。

# 2. 核心方法
- 重参数化骨干 RPB（Re-parameterizable Passage Backbone）：训练时采用多分支卷积（3×3、1×1 与跳过连接），推理时等价融合为单一 3×3 卷积，兼顾训练表达力与推理效率。
- 任务对齐解耦头 TAD-Head（Task-Aligned Decoupled Head）：引入任务交互注意力，使分类得分与边界框质量在特征层先对齐再解耦，缓解分类-定位不一致。
- 动态标签分配 DLA（Dynamic Label Assignment）：以在线聚类方式根据预测质量动态划分正样本，替代固定代价矩阵，提升小目标匹配稳定性。
- 轻量通道蒸馏：以 YOLO26-X 为教师，对 YOLO26-N 做通道级特征蒸馏，补偿小模型精度。
- 实验方案关键设计：数据集为 COCO train2017（118k 图）训练，val2017（5k 图）评测；指标包括 AP、AP50、AP75 及小/中/大目标 AP；硬件平台为骁龙 8 Gen3 NPU、Jetson Orin NX；训练配置为 300 epoch，SGD 优化器，余弦退火学习率调度，初始 lr=0.01。

# 3. 主要创新点
- 提出 YOLO26，一种面向边缘部署的统一检测架构，通过重参数化骨干、任务对齐的解耦检测头与动态标签分配策略，在保持高精度同时显著降低推理开销。
- 设计重参数化骨干 RPB，训练时多分支、推理时等价融合为单一卷积，减少边缘设备计算冗余。
- 提出任务对齐解耦头 TAD-Head，引入任务交互注意力实现分类与定位特征先对齐再解耦，缓解传统检测头表征错位。
- 提出动态标签分配 DLA，以在线聚类动态划分正样本，替代静态标签分配（如 SimOTA 固定代价矩阵），提升尺度变化场景下小目标匹配稳定性。
- 采用轻量通道蒸馏，以 YOLO26-X 为教师对 YOLO26-N 进行通道级特征蒸馏，补偿小模型精度。

# 4. 实验结果与分析
- 本文报告的结果（数据集 COCO val2017，延迟测试硬件骁龙 8 Gen3 NPU）：
  - YOLO26-N：AP=41.2%，AP50=59.8%，延迟 2.1 ms。
  - YOLO26-S：AP=46.5%，延迟 3.4 ms。
  - YOLO26-X：AP=52.3%，AP50=70.1%，延迟 6.8 ms。
  - 消融实验：TAD-Head 贡献 +0.9% AP，DLA 贡献 +0.7% AP。
- 已有方法的结论（基线模型，来自本文引用对比）：
  - YOLOv8-S：AP=44.9%，延迟 4.4 ms（原文给出作为对比基线）。
  - 同量级 YOLOv8 平均指标（摘要提及但未给出具体基线数值）：YOLO26 较其平均提升 1.8% AP 且延迟降低约 23%（此为本文报告对比结论，基线具体值原文未全提供）。
- 对比实验结论：
  - YOLO26-S 对比 YOLOv8-S，在更低延迟（3.4 ms vs 4.4 ms）下反超 1.6% AP（本文报告结果）。
  - 摘要指出 YOLO26-N 与 YOLO26-X 较同量级 YOLOv8 平均提升 1.8% AP 且延迟降低约 23%（本文报告对比结论）。

# 5. 存在不足与未来方向
- 存在不足（论文自身声明）：
  - 在密集行人等极端遮挡场景，漏检率仍高于两阶段方法。
  - 蒸馏依赖大模型教师，训练成本上升。
  - 未验证在视频流时序一致性上的表现。
- 未来方向（论文自身声明）：
  - 拟引入时序建模。
  - 拟引入无教师自蒸馏。
