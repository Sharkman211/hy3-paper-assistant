# 1. 研究目标
- 核心问题：糖尿病视网膜病变（DR）分级依赖眼科医生阅片且医疗资源不均；现有深度学习模型参数量大，难以在边缘设备部署。
- 动机与待填补空白：旨在以轻量结构从眼底彩照自动分级（0-4级），在保持低参数量前提下逼近大模型性能，填补边缘友好型高精度 DR 分级模型的空白。

# 2. 核心方法
- 模型名称：Lite-DRNet，一种轻量双分支网络。
- 分支一（CNN 主干）：采用经通道剪枝的 MobileNetV3 提取病灶纹理，输出多尺度特征。
- 分支二（拓扑分支）：对血管分割图做线性投影后送入轻量 Transformer（4 层，hidden size 256），用于捕获长程血管拓扑，建模血管弯曲/渗漏的全局模式。
- 融合与分类：两分支特征拼接后经分类头输出 5 类概率（对应 0-4 级）。
- 损失函数：kappa-loss + 交叉熵（cross-entropy, CE），权重 1:1，用于监督分类训练。
- 实验方案关键设计：数据集 EyePACS，按患者划分训练集（35k）与验证集（5k）以防泄漏；评价指标包括 quadratic weighted kappa (QWK)、敏感度（重度以上病变）、特异度。

# 3. 主要创新点
- 提出 Lite-DRNet，一种参数量 <5M 的轻量双分支网络，结合 CNN 主干（通道剪枝 MobileNetV3）与轻量 Transformer 拓扑分支，实现眼底彩照 DR 自动分级。
- 在保持 <5M 参数、单图推理 <30ms（T4 GPU）的边缘友好条件下，达到 QWK 0.81，接近 >30M 参数大模型水平，解决现有大模型难以部署的问题（基于摘要与引言目标表述）。

# 4. 实验结果与分析
## 本文报告的结果（Lite-DRNet）
- 数据集：EyePACS（训练 35k / 验证 5k，按患者划分防泄漏）
- 参数量：4.8M
- 单图延迟：28ms (T4 GPU)
- QWK：0.81
- 敏感度（>=3 级，即重度以上病变）：0.93
- 在阈值 0.5 下，重度病变召回 0.93、误报率 6%
- 特异度：原文未充分提供具体数值

## 已有方法的结论（基线模型对比）
- ResNet50：QWK 0.82，敏感度(>=3级) 0.91，参数量 25.6M，单图延迟 41ms (T4)
- EfficientNet-B4：QWK 0.84，参数量 19.3M（原文未提供其敏感度、延迟、特异度数值）

## 对比实验结论
- Lite-DRNet 相比 ResNet50：QWK 低 0.01，敏感度提升 0.02，参数量减少 20.8M，延迟降低 13ms。
- Lite-DRNet 相比 EfficientNet-B4：QWK 低 0.03，参数量减少 14.5M。
- 本文模型以显著更少参数和更低延迟逼近基线大模型 QWK 性能，且在重度病变敏感度上优于 ResNet50。

# 5. 存在不足与未来方向
- 论文自身声明的局限：
  1. 训练数据来自单一种族人群，跨种族泛化需额外验证。
  2. 模型仅作筛查辅助，不替代临床诊断（科普/研究用途，非临床决策）。
- 未来方向（推断）：
  1. 收集多种族眼底彩照数据，进行跨种族泛化验证与适配训练。
  2. 在遵循非临床决策限制前提下，进一步探索边缘设备上的实际筛查辅助部署流程。
